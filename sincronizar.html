Sincronizar con Vinted

Cada vez que subas o vendas algo en Vinted, pulsa el botón y la web se pone al día sola.

✓Datos recibidos de Vinted

    1Instala el botón (solo la primera vez)

    Arrastra este botón a la barra de marcadores de tu navegador (en el ordenador). Si no ves la barra, púlsala con Ctrl + Mayús + B (o Cmd + Mayús + B en Mac).

    Sincronizar JCV

    2Cuando subas o vendas algo

    1. Abre vinted.es con tu sesión iniciada.
    2. Pulsa el marcador "Sincronizar JCV". Leerá todas tus prendas en unos segundos.
    3. Pulsa "Publicar en la web" en el cuadro que aparece. Te traerá de vuelta a esta página.
    4. Revisa el resumen y confirma con "Publicar en la web". En uno o dos minutos la web muestra lo nuevo y marca lo vendido.

    3Conexión con la web

    La web vive en GitHub. Para publicar hace falta un token de GitHub con permiso de escritura solo sobre este repositorio. Se guarda únicamente en este navegador.

    Cómo crear el token
    1. Entra en github.com, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
    2. En "Repository access" elige "Only select repositories" y marca el repositorio de la web.
    3. En "Permissions", "Contents": Read and write. Nada más.
    4. Copia el token y pégalo aquí arriba.
